# EC-003：ヤマト取込用Excel

更新：2026-11-06。対象はEC-003のみ。レビュー・紹介者・年産集計は今回の変更に含めない。

## 仕様元

- ユーザー提供「EC業務改善リスト 11月3日作成.pdf」のEC-003。
- [修正版テンプレート](https://docs.google.com/spreadsheets/d/1khMCTsX9IhkicIDJHQFOObzJIZjmf7gM/edit) の「外部データ取り込み基本レイアウト」A〜AP列・2行目の転記指示。2026-11-06取得版を照合。
- [ヤマト公式操作マニュアル](https://b2-dlserver.kuronekoyamato.co.jp/b2cloud/pdf/b2cloud_manual_05.pdf)。実アカウントへの取込確認は未実施。

## 操作

1. 注文管理：エクスポート → ヤマト取込用Excel。チェック選択があれば選択分、なければ絞り込み結果を出力。
2. 定期購入：2026-11-06の追加指示によりヤマトExcelボタンを削除。「発送予定CSV（確認用）」と対象注文を確認する導線は維持。対象注文のExcelは注文管理から出力できる。
3. ExcelのC列（クール区分）・E列（出荷予定日）を手動入力してから取り込む。データは2行目から。転記指示文はデータ行に入れない。

## 転記

- 42列の順番はテンプレートと一致。見出し行は項目名のみ。未指定の列は空欄。
- A：注文番号。B、F、R、AN、AP：テンプレート指定の固定値。C、E：手動入力用の空欄。
- G：チェックアウトの時間帯を対応コードへ変換。未指定は空欄。認識できない指定はエラーを表示し、無指定に置き換えない。
- I、K、L、P：発送先の電話・郵便番号・住所・氏名。shipping_addressは住所全体を保持しているため、市区町村を重ねて追加しない。建物名も住所に保持し、Mは指示どおり空欄。
- T、V、W、Y：原則注文者情報。発送先と注文者の電話・郵便番号・住所・氏名すべてが一致した場合だけ、テンプレート指定の店舗情報へ切り替える。空白・全半角やハイフン表記を揃えて比較する。
- AB：商品名＋バリエーション。同じ注文内の同じ商品・同じバリエーションをまとめ、数量2以上は「×数量」を付ける。別商品、別バリエーション、別注文はまとめない。
- AG：発送先と注文者が異なる場合だけ指定メッセージを入れ、定期便注文なら「定期便」を追記。一致時は空欄。
- 電話・郵便番号・コードを含め全データセルをExcelの文字列型で出力。数式として解釈しない。マクロ・VBAは含めない。

## 定期便・データ不足

- 対象月の発送回に一致する実注文を既存shipmentTargetsロジックで特定。注文未作成・複数候補がある場合はエラーで案内し、過去注文を代用しない。
- 発送先・注文者の必須情報や商品明細が不足する注文は、注文番号と不足項目を表示して出力を中止。特に旧注文で請求先住所がない場合は実データの確認が必要。
- Excel生成はブラウザー内のみ。DB・注文状態・外部サービス設定を変更しない。

## 実装・検証

- 共通転記：lib/yamatoExport.ts。定期便対象：lib/subscriptionYamato.ts。Excel生成・保存：lib/yamatoWorkbook.ts。
- ExcelJS 4.4.0を固定して追加し、クリック時だけ遅延読み込み。インストール時のスクリプトは実行していない。
- テンプレートから抽出した42列の項目名・順序との一致を独立照合。
- 関連5ファイル32テスト成功：転記・条件分岐・時間帯・数量集約・選択と絞り込み・既存CSV入口・定期便の対象回。Excel書出し後の再読込で42列と文字列型・先頭ゼロ・VBAなしを確認。
- tsc --noEmit --incremental false、git diff --check、本番ビルド成功。
- 独立したLint設定なし。実ブラウザーのダウンロード操作とヤマトB2での取込は未検証。公開後の実取込が最終確認として残る。
