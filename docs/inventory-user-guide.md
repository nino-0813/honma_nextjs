# 在庫管理の使い方

この画面では、玄米を基準に「これから追加で販売できる量」を確認します。年産を選んで使用してください。

## 4つの画面

|画面|使う場面|
|---|---|
|在庫一覧|品種別の残量、注文分、定期便の将来確保を確認する|
|入出庫・販売履歴|追加入庫、直売、卸、贈答、自家用、調整を記録する|
|定期便の発送予定|契約ごとの発送回数・確保量・実注文との対応を確認する|
|設定・過去データ|締切、初期量、商品設定、過去注文の紐付けを登録する|

## 最初に一度行う設定

### 1. 年産を選ぶ

画面上部で対象の年産を選びます。必要な年産がなければ「設定・過去データ」で収穫年を入力して「年産を追加」を押します。

2026年産は令和8年産、2025年産は令和7年産です。過去注文を現在の年産へまとめて登録しないでください。

### 2. 品種ごとの最終発送月を保存する

「設定・過去データ」で「設定する銘柄」を選び、最終発送月と確認根拠を入力し、「期限月を保存・予測再計算」を押します。3品種それぞれで行います。

2026年産の確認済み締切は次のとおりです。画面には初期値が入りますが、保存するまでは未登録です。

|品種|最終発送月|
|---|---|
|コシヒカリ|2027年9月|
|亀の尾|2027年9月|
|にこまる|2027年10月|

締切月の発送分も計算に含めます。他の年産の締切は別途確認してください。

### 3. 玄米の初期量を登録する

同じ画面で、選択した年産・品種について次を入力し、「玄米基準を確認して登録」を押します。

- 玄米総入庫kg：その年産で入庫した玄米の合計
- 旧EC以外の使用済みkg：移行前の直売・卸・贈答・自家用で使用した玄米量
- 旧EC以外の確保中kg：移行前から取り置きしているEC以外の玄米量

**現在の倉庫残量を「総入庫」に入力しないでください。** EC注文は別に計算するので、EC分を使用済み・確保中へ重ねて入力しません。以前の画面に表示された2,900kgなどの数値も、総入庫か現在庫かを記録で確認してから入力してください。

初期量は一度だけ登録できます。登録後の訂正は「入出庫・販売履歴」の「理由付き調整」を使用します。初期量の根拠が不明なら、推測で入力せず確認を続けてください。

### 4. 商品を登録する

「商品設定 / 過去注文の確認」で次を入力します。

1. 対象：「これからの注文の商品設定」
2. 商品と、その商品の選択肢（白米・玄米など）
3. 年産・品種・商品重量・精米方法
4. 確認根拠・理由
5. 「確認して保存」

重量は**1個分の製品重量**です。コシヒカリ5kg白米なら「5kg」「白米」を選びます。画面に「必要な玄米：5.5kg／個」と表示されます。5.5kgを重量欄へ入力すると二重に換算されるため、5kgを入力してください。

|精米方法|玄米への換算|5kg商品の例|
|---|---|---|
|白米|×1.1|5.5kg|
|分づき|×1.05|5.25kg|
|玄米|×1|5kg|

同じ商品の白米・玄米など、選択肢の組合せごとに登録します。セット商品は「＋ セットのお米を追加」で構成品を増やします。ライスキープ・柿・椎茸などは「米ではない」にチェックします。

### 5. 過去注文を確認する

「未判定・要確認一覧」で注文番号・商品名を検索し、「この注文を確認」を押します。対象が「過去の注文明細を確認」に切り替わります。

発送記録や当時の商品情報で、年産・品種・精米方法を確認し、1個分の重量と理由を入力して保存します。2個注文なら数量は自動で掛けるため、入力重量を2倍にしません。

今後の商品設定を登録しても過去注文は自動では確定しません。年産・精米不明、明細欠落、確定後の変更、旧重量基準の登録済み明細は、注文管理や履歴の照合が必要です。確認できない注文は未判定のまま残します。

### 6. 定期契約の発送予定を登録・照合する

「定期便の発送予定」の「定期便の初回・再開発送日を確認」で次を選びます。

1. 契約
2. 商品と登録済みの商品・精米設定
3. 記録で確認した初回／再開発送日
4. 1回の数量と確認根拠
5. 「契約を確認・発送回を生成」

周期は契約の登録内容を使用します。初回発送日と次回発送日を取り違えないでください。生成後、回数・日付・品種・重量が実際の配送予定と合うか確認します。

例：コシヒカリ5kg白米、2か月おき、2026年12月初回発送の場合、12・2・4・6・8月の5回。玄米は5×5×1.1＝27.5kgを確保します。

既存の定期注文がある場合は「実注文を発送回へ紐付け」で、同じ契約の発送回と注文明細を1回ずつ照合します。「予測を注文確保に置き換え」を押すと、予測と注文を二重に差し引かないよう対応づけます。日付だけで発送済みと決めず、出荷記録を確認してください。

複数の定期商品を含む契約や休止情報が不明な契約などは、現版で確認が必要になる場合があります。「要確認」を解消するために架空の設定を登録しないでください。

## 毎日の操作

### 残量を見る

「在庫一覧」で年産を選び、「更新」を押します。品種別カードで残量と内訳を確認できます。

追加販売できる量＝入庫・調整後－販売・使用済み－注文済み未発送－定期便の将来確保－その他の確保。

「未確定」「確認済み分の参考残量」と表示される場合、未判定や初期設定が残っています。参考値をそのまま追加販売可能量として扱わず、「設定・過去データ」で確認します。

### 直売・卸・贈答・自家用を記録する

「入出庫・販売履歴」で品種・区分・精米区分・製品重量・理由／販売先を入力し、「履歴に追加」を押します。白米5kgを直売したら、製品重量5kg、白米を選びます。玄米5.5kgとして計算します。

入庫は増えた玄米kg、調整は増減した玄米kgを入力します。EC注文・定期便の将来分はこのフォームへ再入力しません。

### 定期便の解約・変更・スキップ

既存の定期購入の操作画面で手続きし、「定期便の発送予定」と「在庫一覧」を更新して結果を確認します。

- 解約：まだ注文になっていない将来確保を解除
- 品種・重量・数量・精米・周期の変更：未紐付けの将来回を再計算
- 発送済み分：元の品種・重量の記録を保持
- 作成済み注文：契約変更だけでは内容が変わらないため、注文管理で確認
- 発送：確認済みの注文確保を使用済みへ振り替える

休止・未照合・変更内容不明などで「要確認」が出た場合、旧確保を維持することがあります。顧客側の重量変更には既存の受付制限があり、この在庫画面の改修で解除はしていません。

## 間違って登録したとき

増減履歴を確認し、同じデータをもう一度入力する前に保存状況を確認します。初期量や履歴を削除して合わせず、「理由付き調整」で根拠を残します。発送済み返品は返金だけで在庫に戻らないため、現物を検品してから必要な調整を記録してください。
